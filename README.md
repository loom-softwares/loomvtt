## 🐛 Bug Reports & Feature Requests

Found a bug? Have an idea? Use the links below to open the right type of issue:

| Type | Description | Link |
|------|-------------|------|
| 🐛 **Bug Report** | Something is broken or behaving incorrectly | [Open →](../../issues/new?template=bug_report.yml) |
| ✨ **Feature Request** | Suggest a new feature or improvement | [Open →](../../issues/new?template=feature_request.yml) |
| ⚡ **Performance Issue** | FPS drops, slow loading, lag | [Open →](../../issues/new?template=performance.yml) |
| 📚 **Documentation** | Missing or unclear documentation | [Open →](../../issues/new?template=docs_request.yml) |
| ❓ **Question** | General question or help needed | [Open →](../../issues/new?template=question.yml) |
| 🔒 **Security Vulnerability** | See [SECURITY.md](./SECURITY.md) for private reporting | — |

**Before opening an issue**, please:
1. Check [existing issues](../../issues) to avoid duplicates
2. Read [CONTRIBUTING.md](./CONTRIBUTING.md) for tips on writing a good report
