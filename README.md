This repository serves as the central hub for tracking planned features, feature requests, bugs, and other issues for [LoomVTT](https://loomvtt.com) software.

LoomVTT is a next-generation, extensible Virtual Tabletop built for modern role-playing games. Engineered from the ground up with TypeScript and native web technologies, it delivers blazing-fast performance, a robust real-time multiplayer engine, and a powerful SDK for addon and ruleset developers. LoomVTT runs as a self-hosted desktop application on Windows, macOS, and Linux — players connect for free directly through a web browser.

---

## Issue Tracker

Our issue tracker provides a simple overview and project management tools for outlining planned work on the core software, and allows users to easily follow how development is progressing. More detailed than a simple roadmap, users can filter specific types of issues through GitHub labels, or use our project views to see work scoped to particular milestones.

The LoomVTT development team uses GitHub Projects to organize and scope the planned work for each phase of a new software version. Through specific filters and project boards, users can easily stay up to date:

**[Current Projects](../../projects?query=is%3Aopen)**
Project boards are generally the best way to see everything planned at the scale of a full software version. If you want a complete picture of what's coming, this is where to look.

**[Current Milestones](../../milestones)**
Milestones compartmentalize the section of a version we are actively working on. Each milestone displays the work completed in a particular release, rather than an entire version.

**[Labels](../../labels)**
Labels are an efficient way to check whether someone has already filed a bug report or feature request similar to yours. They can also be used to browse issues related to specific parts of the software.
