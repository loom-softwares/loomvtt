# Security Policy

## Supported Versions

Only the latest publicly available version of LoomVTT receives security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ❌        |

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

If you discover a security vulnerability in LoomVTT, please report it responsibly by contacting us directly:

- **Email**: security@loomvtt.com *(or contact via Discord DM to the maintainer)*
- **Subject**: `[SECURITY] Brief description of the issue`

### What to include

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact (what an attacker could do)
- Any suggested mitigations (optional)

### What to expect

- **Acknowledgment** within 72 hours
- **Assessment** within 7 days
- **Fix or mitigation** for confirmed vulnerabilities as soon as feasible
- Credit in the changelog (if desired) once the issue is resolved

We take security seriously. Thank you for helping keep LoomVTT and its users safe.
