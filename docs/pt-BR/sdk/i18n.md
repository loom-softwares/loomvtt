# i18n — Localização de ruleset (`ruleset-i18n.ts`)

Registro de strings de idioma em runtime para um ruleset convertido. Exposto em
`window.Loom.i18n` (e via helper `{{localize}}` do Handlebars — ver `handlebars-helpers.md`).

```typescript
// Não é export do SDK — só existe como global window.Loom.
Loom.i18n.registerLang(/* ... */);
```

## API

```typescript
Loom.i18n.registerLang(locale: string, bundle: Record<string, any>): void;
Loom.i18n.localize(key: string): string;
Loom.i18n.format(key: string, data?: Record<string, string | number>): string;
```

- `registerLang`: registra (ou faz merge profundo em) um bundle pra um locale.
- `localize`: resolve `key` por notação de ponto (`'sheet.name'`) no locale atual
  (`document.documentElement.lang`, fallback `en`); se não achar, cai pra chave core e, por
  fim, **retorna a própria chave** — nunca lança erro (paridade com o contrato de sistemas
  convertidos).
- `format`: faz `localize` e substitui `{placeholders}` pelos valores de `data`.

## Exemplo

```js
// Registrar bundles de idioma (um ruleset convertido faz isso no entry .mjs)
Loom.i18n.registerLang('en', { sheet: { name: 'Name' } });
Loom.i18n.registerLang('pt-BR', { sheet: { name: 'Nome' } });

const label = Loom.i18n.localize('sheet.name');  // depende do lang do doc
const greeting = Loom.i18n.format('sheet.greeting', { name: 'Aria' }); // "Olá Aria"

// No template
// {{localize "sheet.name"}}
// {{localize "sheet.greeting" name=actor.name}}
```
