# i18n — Ruleset Localization (`ruleset-i18n.ts`)

Runtime language strings registry for a converted ruleset. Exposed in
`window.Loom.i18n` (and via the `{{localize}}` Handlebars helper — see `handlebars-helpers.md`).

```typescript
// Not an SDK export — only exists as the window.Loom global.
Loom.i18n.registerLang(/* ... */);
```

## API

```typescript
Loom.i18n.registerLang(locale: string, bundle: Record<string, any>): void;
Loom.i18n.localize(key: string): string;
Loom.i18n.format(key: string, data?: Record<string, string | number>): string;
```

- `registerLang`: registers (or deeply merges into) a bundle for a locale.
- `localize`: resolves `key` by dot notation (`'sheet.name'`) in the current locale
  (`document.documentElement.lang`, fallback `en`); if not found, falls back to the core key and, finally,
  **returns the key itself** — never throws an error (parity with the contract of converted
  systems).
- `format`: runs `localize` and replaces `{placeholders}` with values from `data`.

## Example

```js
// Register language bundles (a converted ruleset does this in the entry .mjs)
Loom.i18n.registerLang('en', { sheet: { name: 'Name' } });
Loom.i18n.registerLang('pt-BR', { sheet: { name: 'Nome' } });

const label = Loom.i18n.localize('sheet.name');  // depends on the doc's lang
const greeting = Loom.i18n.format('sheet.greeting', { name: 'Aria' }); // "Hello Aria"

// In the template
// {{localize "sheet.name"}}
// {{localize "sheet.greeting" name=actor.name}}
```
