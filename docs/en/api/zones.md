# Zones (Trigger Zones)

## Endpoints

**Base:** `/api/zones`
**Auth:** `requireAuth, requireWorldMatch`

---

### GET `/stage/:stageId`

Lists trigger zones of a stage, oldest first.

**Response `200`:** `ZonesDocument[]`
**Response `500`:** `{ "error": "..." }`

---

### POST `/`

Creates zone. The id is generated by the server (`zone-<uuid>`).

| Field | Type | Required | Default |
|-------|------|-------------|---------|
| `stageId` | `string` | **yes** | — |
| `name` | `string` | **yes** | — |
| `shape` | `string` | no | `'rect'` |
| `x` | `number` | no | `0` |
| `y` | `number` | no | `0` |
| `width` | `number` | no | `100` |
| `height` | `number` | no | `100` |
| `points` | `array` | no | `[]` |
| `handlers` | `array` | no | `[]` |

**Response `201`:** Zone created (the zone row)
**Response `400`:** `{ "error": "stageId and name are required" }`
**Response `500`:** `{ "error": "..." }`
**Internal Event:** Signal `zone.created` (server-side only; it is **not** relayed to WebSocket clients)

---

### PUT `/:id`

Updates zone. Partial update of `name`, `shape`, `x`, `y`, `width`, `height`, `points`, `handlers`.

**Response `200`:** Zone updated (the zone row)
**Response `404`:** `{ "error": "..." }` (zone not found)
**Response `500`:** `{ "error": "..." }`
**Internal Event:** Signal `zone.updated` (server-side only; **not** relayed to WebSocket clients)

---

### DELETE `/:id`

Removes zone.

**Response `200`:** `{ "success": true }`
**Response `404`:** `{ "error": "..." }` (zone not found)
**Response `500`:** `{ "error": "..." }`
**Internal Event:** Signal `zone.deleted` (server-side only; **not** relayed to WebSocket clients)
