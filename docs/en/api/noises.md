# Noises (Ambient Sounds)

## Endpoints

**Base:** `/api/noises`
**Auth:** `requireAuth, requireWorldMatch`

---

### GET `/stage/:stageId`

Lists ambient sounds of a stage, ordered by `createdAt`.

**Response `200`:** `NoisesDocument[]`
**Response `500`:** `{ "error": "..." }`

---

### POST `/`

Creates ambient sound. The id is generated by the server as `noise-<uuid>`.

| Field | Type | Required | Default |
|-------|------|-------------|---------|
| `stageId` | `string` | **yes** | - |
| `src` | `string` | no | - |
| `levelId` | `string` | no | `''` |
| `x` | `number` | no | `0` |
| `y` | `number` | no | `0` |
| `radius` | `number` | no | `300` (the schema default is `100`, but the route applies `300`) |
| `volume` | `number` | no | `1.0` |
| `easing` | `boolean` | no | `true` |
| `hidden` | `boolean` | no | `false` |
| `darknessMin` | `number` | no | `0` |
| `darknessMax` | `number` | no | `1` |
| `wallsBlock` | `boolean` | no | `false` |

Spatial audio fields:
- `hidden` - the client sound manager skips hidden sounds (`client/canvas/sound-manager.ts:161`, `:229`). Whether the GM still hears them is UNVERIFIED
- `darknessMin`/`darknessMax` - darkness range (0.0-1.0) in which the sound is audible
- `wallsBlock` - walls block the sound (uses `raySegmentIntersection`)

**Response `201`:** Created sound
**Response `400`:** `{ "error": "stageId is required" }` or the Document error
**WS Event:** `noise.created` (payload: the created row, relayed to all clients)

---

### PUT `/:id`

Updates sound. Accepts the fields `src`, `x`, `y`, `radius`, `volume`, `easing`, `hidden`,
`darknessMin`, `darknessMax`, `wallsBlock` and `levelId`; other fields are ignored.

**Response `200`:** Updated sound
**Response `404`:** `{ "error": "..." }` (Document error)
**WS Event:** `noise.updated` (payload: the updated row, relayed to all clients)

---

### DELETE `/:id`

Removes sound.

**Response `200`:** `{ "success": true }`
**Response `404`:** `{ "error": "..." }` (Document error)
**WS Event:** `noise.deleted` (payload: `{ "id" }`, relayed to all clients)

---

## Spatial Audio (Client-Side)

The `SoundManager` (`client/canvas/sound-manager.ts`) uses `AudioContext` + `PannerNode` with HRTF and inverse distance:

- **Attenuation:** volume decreases with distance to the sound center (150ms threshold)
- **Stereo panning:** relative position to the listener
- **Walls:** if `wallsBlock=true`, raycasts from listener to sound - wall intersection silences the sound
- **Darkness:** `darknessMin`/`darknessMax` control in which illumination range the sound is audible
- **Hidden:** hidden sounds are only audible to the GM

The listener is synchronized with the controlled token via `CanvasManager.updateControlledTokens()`.
