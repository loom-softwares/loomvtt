# Campaigns

## Endpoints

**Base:** `/api/campaigns`
**Auth:** `requireAuth, requireWorldMatch`. `GET` is open to every logged-in user; `POST`, `PUT` and `DELETE` require GM (`requireGM`, 403 otherwise).

---

### GET `/`

Lists campaigns, ordered by `createdAt` ascending. Campaigns are not tied to a world: the list is the same in every world, and any signed-in session sees all of them.

**Response `200`:** `CampaignsDocument[]`

---

### GET `/:id`

Fetches campaign by ID.

**Response `200`:** `CampaignsDocument`
**Response `404`:** `{ "error": "Campaign not found" }`

---

### POST `/`

Creates campaign. The id is generated by the server (`camp-<uuid>`). No permission check beyond the session.

| Field | Type | Required | Default |
|-------|------|----------|---------|
| `name` | `string` | **yes** | — |
| `description` | `string` | no | `''` |
| `manifest` | `object` | no | `{}` |

**Response `201`:** the created campaign
**Response `400`:** `{ "error": "name is required" }`

**Internal events:** Signal `campaign.created`, and the generic `campaigns.created` from the Document layer (server-side, **not relayed** to WebSocket — see [websocket/events.md](../websocket/events.md))

---

### PUT `/:id`

Updates campaign. Body: any of `name`, `description`, `manifest`.

**Response `200`:** the updated campaign
**Response `404`:** returned for any error from the update (not just "not found")

**Internal events:** Signal `campaign.updated`, and the generic `campaigns.updated` (server-side, **not relayed** to WebSocket — see [websocket/events.md](../websocket/events.md))

---

### DELETE `/:id`

Removes campaign.

**Response `200`:** `{ "success": true }`
**Response `404`:** returned for any error from the delete

**Internal events:** Signal `campaign.deleted`, and the generic `campaigns.deleted` (server-side, **not relayed** to WebSocket — see [websocket/events.md](../websocket/events.md))
